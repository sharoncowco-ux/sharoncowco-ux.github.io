Preguntas frecuentes

La mayoría de personas que quiere información rápida y corta sobre nuestros cursos normalmente nos hacen estas tres preguntas.

¿Qué es CSS?

Es el lenguaje de programación de diseño que se utiliza para darle estilo, color, formato y estructura visual a las páginas web escritas en HTML.Se llama "en cascada" porque las reglas de estilo se pueden aplicar en orden de jerarquía: si una regla general dice que todos los textos son azules, pero una regla específica dice que un párrafo en concreto es rojo, el navegador aplicará el color rojo por tener mayor prioridad.

¿Qué aprenderé en este curso?

En este curso de CSS aprendes a darle estilo, diseño y estructura visual a las páginas web. Pasas de tener una página en texto plano en HTML a crear un sitio web profesional y moderno.

¿Qué es CSS GRID?

CSS Grid (o Grid Layout) es un sistema de diseño bidimensional para CSS. Está diseñado para manejar filas y columnas al mismo tiempo, lo que lo convierte en la herramienta más potente para estructurar la maquetación completa de una página web o secciones complejas.
